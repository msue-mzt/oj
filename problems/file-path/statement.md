Багш сурагчдадаа компьютер дээрх файлын замыг хэвлэдэг программ бичүүлжээ. Гэтэл зам дотор `\` болон `"` тэмдэг байгаа тул энгийнээр бичвэл программ хөрвүүлэгдэхгүй.

Дараах хоёр мөрийг яг адилхан хэвлэ:

```
C:\Olymp\"Bat"\main.cpp
Tab is \t and newline is \n
```

Хоёр дахь мөрөнд `\t`, `\n` нь табуляци, шинэ мөр **биш**, харин яг тэр чигтээ хоёр тэмдэгт байдлаар харагдах ёстой.
