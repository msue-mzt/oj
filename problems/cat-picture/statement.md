Сурагчид ангийнхаа ханын сонинд зориулж тэмдэгтээр зураг зурдаг программ бичихээр болжээ. Дараах зургийг хэвлэ:

```
 /\_/\    "Meow!"
( o.o )  /
 > ^ <  \\ C++ //
/|   |\  ''"''
%d %s \n 100%
```

Анхаар: сүүлийн мөрөнд `\n` нь шинэ мөр биш, хоёр тэмдэгт. Тэмдэгт бүр яг таарах ёстой (үг хоорондын хоосон зайн тоо хамаагүй). Нэг ч `\` эсвэл `"` алдвал хариу буруу болно.

## Зөвлөгөө
